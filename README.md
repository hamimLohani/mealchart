# Meat Chart

Multi-group hostel and mess meal management app built with `Next.js`, `Tailwind CSS`, `Firebase`, and `Zustand`.

## Overview
The application is a real-time web platform where each mess or hostel is considered a **Group**. The app provides group-based authentication via unique tokens, separating regular members from group administrators. It handles everything from daily meal tracking to cost management and monthly history in real-time, supporting both English and Bengali, as well as Light and Dark modes.

---

## 1. Authentication & Access Management

### Group Registration
- **Target User**: Group Admin
- **Description**: Admins can register a new group by providing a group name, admin email, and password. 
- **Token Generation**: Upon successful registration, the app generates a unique group token.

### Enter Group (Login)
- **Target User**: Group Members
- **Description**: Members do not need individual accounts. They access their specific group's dashboard using the unique group token generated by the admin.
- **Admin Access**: Admins use their email and password to log in and access administrative privileges.

---

## 2. Group Member Dashboard (Main Page)

Once a member enters using the group token, they access the main group dashboard which includes:

### Daily Meal Tracking
- **Feature**: View today's meal status.
- **Action**: Input box and "Add Meal" button allowing members to add meals for the current day.
- **Real-time**: Updating a meal instantly updates the `individual_total_meal` for that member.

### Chart View Page
- **Description**: Displays the current month at the top. Shows a comprehensive list of all meals for all members categorized by date.
- **Statistics Shown**:
  - Individual total meals.
  - Overall total meals of the group.
  - Total paid money (`total_paid_taka`).
  - Total costs (`total_cost`).
  - Current Meal Rate (`total_cost / total_meal`).

### Money Management Page
- **Description**: Financial overview for the current month.
- **Information Displayed**:
  - Record of all cash paid to the admin.
  - Total cost history (bazar) with dates.
  - Calculated Meal Rate.
  - Total money consumed by each person (`eaten_taka = meal_rate * individual_total_meal`).
  - Remaining balance for each member (`individual_total_taka - eaten_taka`).

### History Page
- **Description**: Archive of previous months.
- **Action**: Members can click on any previous month to view a snapshot of that month's Chart View.

### Notice Board
- **Description**: A read-only view for members to see all announcements and notifications posted by the admin (e.g., when a new member is added, costs are updated, or money is deposited).

---

## 3. Administrator Dashboard

Admins have a dedicated interface (accessed via email/password login) with elevated privileges to manage the group.

### Member Management (`/admin/members`)
- **Actions**:
  - Add new members (Full name, join date, phone number).
  - Search, edit, and remove members.
- **Logic**: Adding a member mid-month assigns them 0 meals for the previous days.
- **Automation**: Adding a member automatically posts a notification to the Notice page.

### Costs / Bazar Tracking (`/admin/costs`)
- **Actions**:
  - Form to input item name, total cost, and date.
  - Submitting the form adds to the group's `total_cost`.
- **Automation**: Automatically posts a notification to the Notice page.

### Money Management (`/admin/add-money`)
- **Actions**:
  - View current balances (`individual_total_money`).
  - Add newly deposited money to a member's account.
  - View overall group funds (`total_paid_taka`).
- **Automation**: Automatically posts a notification to the Notice page.

### Edit Meal Chart
- **Actions**: A table view allowing the admin to override or edit any member's meal count for any date in the current month. Edits reflect instantly across all calculations.

### Chart Initialization
- **Actions**: Button/Interface to "Create New Chart".
- **Logic**: Generates a new 31-day cycle, resetting calculations to start fresh for the new month, while archiving the old data to the History page.

### Notice Management
- **Actions**: Add, edit, or delete notices directly.

---

## 4. System & UI Capabilities

- **Real-time Sync**: Firebase/Firestore integration ensures that all calculations (meals, costs, balances) update in real-time across all connected devices.
- **Internationalization (i18n)**: Full support for both **English** and **Bangla** languages, toggleable via the header.
- **Theming**: Integrated **Light Mode** and **Dark Mode** toggle in the header, utilizing global CSS variables and Tailwind CSS.
- **Responsive UI**: Built with Next.js, React, and Tailwind CSS for a seamless desktop and mobile experience.

## Setup

1. Copy `.env.example` to `.env.local`
2. Fill in your Firebase web app credentials
3. Install dependencies:

```bash
npm install
```

4. Start the app:

```bash
npm run dev
```

5. Follow the full Firebase connection guide:

- [FIREBASE_SETUP.md](./FIREBASE_SETUP.md)
